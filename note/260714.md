# C言語：文字列の扱い

C言語において、文字列は**`char`型の配列**として管理します。

### 📌 文字列の構造（メモリイメージ）

| 配列の添字 | `[0]` | `[1]` | `[2]` | `[3]` | `[4]` | `[5]` | `[6]` |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **格納データ** | 'U' | 'e' | 'j' | 'o' | 'b' | 'i' | `\0` |

* **`'U'` 〜 `'i'`** : 実際の文字データ
* **`'\0'`** : NULL（ヌル）文字。**文字列の終端（終わり）**を示します。

### 📌 入出力のルール
* 文字列の入出力には、書式指定子 **`%s`** を使用します。

---

### 💻 サンプルコード：文字列の入出力

```c
#include <stdio.h>

int main(void) {
    // 実際に必要な長さよりも、少し多めに配列サイズを確保する
    // ※末尾のNULL文字を含めるため、この場合は最大127文字まで格納可能
    char str[128];

    // 文字列の入力
    // ※「%s」のときは変数名の前に「&」を付けません（配列名自体がアドレスを示すため）
    scanf("%s", str);

    // 文字列の出力
    printf("入力した文字列は「%s」です。\n", str);

    return 0;
}
```

---

### 📌 文字列の初期化と数値変換

* **自動的なサイズ決定**: 初期値を代入して配列を宣言するときは、要素数（サイズ）を省略できます。
* **型変換**: 文字列として入力された数字を計算に使うには、数値型への変換が必要です。

#### 💡 変換に使う主な関数
* **`atoi`** (ASCII to Integer): 文字列を **整数（`int`）** に変換
* **`atof`** (ASCII to Float): 文字列を **実数（`double`）** に変換
* ※これらを使用する際は **`#include <stdlib.h>`** が必要です。

---

### 💻 サンプルコード：文字列の初期化と数値への変換

```c
#include <stdio.h>
#include <stdlib.h> // atoiを使用するために必要

int main(void) {
    // 初期値を与えるときは、文字数（＋NULL文字）で自動的にサイズが決まる
    // この場合は {'2', '0', '\0'} が格納されるため要素数は3になる
    char age[] = "20"; 

    printf("年齢は："); 
    scanf("%s", age);

    // 文字列から整数（int型）へ変換
    int i_age = atoi(age); 

    // 計算して出力
    printf("10年後は%d歳です。\n", i_age + 10);

    return 0;
}
```

---

### 📌 途中に NULL 文字（`'\0'`）を代入した場合の挙動

* 文字列の途中に `'\0'` を書き込むと、そこが**新しい文字列の終端**として扱われます。
* メモリ上にはそれ以降のデータも残っていますが、`printf` などの文字列処理関数は `'\0'` を見つけた時点で処理を終了するため、それ以降は出力されません。

#### 💻 サンプルコード：途中で文字列を打ち切る

```c
#include <stdio.h>

int main(void) {
    // 変更可能な配列として文字列を初期化
    char str[] = "hello world!";

    // 3番目（4文字目）の要素に NULL 文字を代入
    str[3] = '\0';

    // 3文字目以降にもデータは残っていますが、表示は「hel」で止まります
    printf("文字列は「%s」です。\n", str); 

    return 0;
}
```

### 📌 文字列の操作

#### 💡 文字列の長さを求める自作関数
C言語の文字列は末尾に `'\0'` があるという特徴を利用し、先頭から `'\0'` に到達するまでカウントを進めることで文字数をカウントできます。

```c 
#include <stdio.h>

// 引数に渡された文字列の長さを返す関数（定数として扱うため const を付与）
int str_length(const char s[]) {
    int len = 0;

    // NULL文字「'\0'」に到達するまでループを回す
    while (s[len] != '\0') {
        len++;
    }

    // '\0' を除いた純粋な文字数を返す
    return len;
}

int main(void) {
    char text[] = "Uejobi";
    printf("文字数は %d です。\n", str_length(text)); // 「6」が出力される
    return 0;
}
```
