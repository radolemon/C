# C言語：文字列をコピーする関数の実装

文字列を1文字ずつコピーするカスタム関数 `str_cpy` の実装例です。

## 修正済みのソースコード

```c
#include <stdio.h>

/* 
 * 文字列コピー関数
 * s1: コピー先配列, s2: コピー元配列
 */
void str_cpy(char s1[], const char s2[]) {
    int i;

    /* 1文字ずつ順番にコピー (ナル文字 '\0' に達するまでループ) */
    for (i = 0; s2[i] != '\0'; i++) {
        s1[i] = s2[i];
    }
    
    /* コピー先文字列の末尾にナル文字を追加して正常に終了させる */
    s1[i] = '\0';
}

int main(void) {
    char str1[] = "Uejobi";
    
    /* 
     * 【修正ポイント】
     * コピー先には十分なメモリサイズを確保する必要があります。
     * 配列の要素数を空（str2[]）にすると、文字を保存する領域がないためエラーになります。
     */
    char str2[10]; 

    /* str1 の内容を str2 にコピー */
    str_cpy(str2, str1);

    /* 結果の表示 */
    printf("コピー：%s\n", str2);

    return 0;
}
```

## 主なポイントと修正理由

* **ヘッダーファイルの追加**: `printf` を使用するため、冒頭に `#include <stdio.h>` を追加しました。
* **配列サイズの指定**: 元のコードの `char str2[];` は、コンパイルエラーまたは実行時エラーの原因になります。C言語では、コピー先の配列にあらかじめ十分な大きさ（今回の "Uejobi" はナル文字含め7バイトなので `[10]` など）を確保しておく必要があります。
* **代入の禁止**: コメントにある通り、C言語では `s1 = s2;` のような配列全体の直接代入はできません。そのため、関数内で `for` 文を使って1文字ずつ代入しています。
