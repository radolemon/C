## (引数あり、戻り値あり)
```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int n1, n2;

    scanf("%d", &n1);
    scanf("%d", &n2);

    printf("それらの和は%dです。\n", add(n1, n2));

    return 0;
}
```

# プロトタイプ宣言
「使う予定の関数」の名前、引数、戻り値の型を、あらかじめコンピュータに伝えておくこと
あらかじめ伝えることで関数をどの順番で書いても問題なく動く
## プロトタイプ宣言の書き方
- 関数の処理の前にまとめて書く
- 引数は<span style="color: #f88;">型名のみ</span>を書く(変数名は書かない)
- 最後に<span style="color: #f88;">セミコロン</span>を付ける

```c
int max2(int, int);
int min2(int, int);
int max3(int, int, int);
int maxmin2(int, int, int);

/*(自作関数、main関数の処理を書く)*/
```

## 例：List4-2 (サブルーチン化)
```c
int input_hand(void); // プロトタイプ宣言
void show_hand(int); // プロトタイプ宣言

int main(void) {
    int hand;
    hand = input_hand();
    show_hand = show_hand(hand);

    return 0;
}

int input_hand(void) {
    int hand;

    do {
        printf("手を選んでください [0...グー/1...チョキ/2...パー] :");
        scanf("%d", &hand);
    } while (hand < 0 || hand > 2);

    return hand;
}

void show_hand(int h) {
    printf("あなたは");
    switch (h) {
        case 0: printf("グー"); break;
        case 1: printf("チョキ"); break;
        case 2: printf("パー"); break;
    }
    printf("を選びました。\n");
}
```
