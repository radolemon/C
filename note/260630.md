# C言語：関数の設計とプロトタイプ宣言

C言語における関数の4つの設計パターンと、プロトタイプ宣言の重要ルールを整理しました。アンカーリンク（ページ内リンク）も維持したまま、綺麗にコピー＆ペーストして活用できます。

## 🎯 関数の設計（4つのパターン）

関数は「引数（ひきすう：関数に渡すデータ）」と「戻り値（もどりち：関数から返ってくる結果）」の有無によって、以下の4パターンに分類されます。

* [1. 引数あり・戻り値あり](#func01)
* [2. 引数あり・戻り値なし](#func02)
* [3. 引数なし・戻り値あり](#func03)
* [4. 引数なし・戻り値なし](#func04)

---

<a id="func01"></a>
### 1. 引数あり、戻り値あり
データを関数に渡し、計算結果を呼び出し元に返して利用する、最も標準的な設計です。
```c
int add(int a, int b) {
    return a + b; // 計算結果を戻り値として返す
}

int main(void) {
    int n1, n2;
    scanf("%d", &n1);
    scanf("%d", &n2);

    // add関数の戻り値をそのままprintfで出力
    printf("それらの和は%dです。\n", add(n1, n2));
    return 0;
}
```

<a id="func02"></a>
### 2. 引数あり、戻り値なし
データを関数に渡しますが、結果は返さず、関数側で画面出力などの処理を完結させます。
```c
void add(int a, int b) { // 戻り値がない場合は「void」を指定
    printf("それらの和は%dです。\n", a + b); // 関数内で出力まで行う
}

int main(void) {
    int n1, n2;
    scanf("%d", &n1);
    scanf("%d", &n2);

    add(n1, n2); // 関数を呼び出すだけ（受け取る変数は不要）
    return 0;
}
```

<a id="func03"></a>
### 3. 引数なし、戻り値あり
関数には何もデータを渡しません（`void`）。関数の中で入力などを行い、その結果だけを呼び出し元に返します。
```c
int add(void) { // 引数がない場合は「void」を指定
    int n1, n2;
    scanf("%d", &n1);
    scanf("%d", &n2);
    return n1 + n2;
}

int main(void) {
    // 引数を持たずに呼び出し、返ってきた結果を出力
    printf("それらの和は%dです。\n", add());
    return 0;
}
```

<a id="func04"></a>
### 4. 引数なし、戻り値なし
データの受け渡しも、結果の返却もありません。一連のまとまった処理（メッセージ表示など）を丸ごと別枠で実行させたい場合に使います。
```c
void add(void) { // 引数も戻り値も「void」
    int n1, n2;
    scanf("%d", &n1);
    scanf("%d", &n2);
    printf("それらの和は%dです。\n", n1 + n2);
}

int main(void) {
    add(); // シンプルに呼び出すだけ
    return 0;
}
```

## 📢 プロトタイプ宣言

### プロトタイプ宣言とは？
「これから使う予定の関数」の名前、引数の型、戻り値の型を、あらかじめコンパイラに伝えておく仕組みです。
これを行うことで、**自作関数を `main` 関数より後ろに書いてもエラーにならず、記述する順番を自由に変更できる**ようになります。

### ✍️ 書き方の3大ルール
1. **書く場所**：実際の処理（`main`関数など）が始まる前にまとめて記述する。
2. **引数の省略**：引数の部分は**「型名のみ」**を書き、変数名は省略する。
3. **末尾の記号**：文の最後には必ず**「セミコロン（`;`）」**を付ける。

```c
// プロトタイプ宣言の例
int max2(int, int);       // 変数名は書かない、最後に「;」
int min2(int, int);
int max3(int, int, int);
```

## 💻 応用例：じゃんけんの手の入力と表示（サブルーチン化）

プロトタイプ宣言を活用し、処理を機能ごとに「サブルーチン（独立した関数）」として分けた実践的なコード例です。

```c
#include <stdio.h>

// --- プロトタイプ宣言 ---
int input_hand(void); // 引数なし、戻り値あり（入力された手を受け取る）
void show_hand(int);  // 引数あり、戻り値なし（手を画面に表示する）

int main(void) {
    int hand;
    
    // 自作関数がmainより後ろにあっても、プロトタイプ宣言があるため正常に動く
    hand = input_hand();
    show_hand(hand);

    return 0;
}

// --- 関数定義：正しい手が選ばれるまで入力を繰り返す ---
int input_hand(void) {
    int hand;
    do {
        printf("手を選んでください [0...グー/1...チョキ/2...パー] :");
        scanf("%d", &hand);
    } while (hand < 0 || hand > 2); // 0〜2以外は再入力
    
    return hand;
}

// --- 関数定義：選ばれた手を画面に出力する ---
void show_hand(int h) {
    printf("あなたは");
    switch (h) {
        case 0: printf("グー"); break;
        case 1: printf("チョキ"); break;
        case 2: printf("パー"); break;
    }
    printf("を選びました。\n");
}
```
