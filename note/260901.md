# C言語：ポインタの使い方ガイド

## 1. ポインタが必要になる背景

### ❌ 失敗例1：複数の値を返すことはできない
C言語の `return` 文は、1つの値しか返せません。
```c
int sum_diff(int a, int b) {
    int sum = a + b;
    int diff = a - b;

    // return sum, diff; ❌ このように2つの値を同時にreturnすることはできません
}
```

### ❌ 失敗例2：値渡しでは呼び出し元の変数を変えられない
引数として値をそのまま渡すと、関数内には「値のコピー」が作られます。そのため、関数内で書き換えてもメインルーチン（呼び出し元）の値は変わりません。
```c
void sum_diff(int a, int b, int sum, int diff) {
    sum = a + b;
    diff = a - b;
} // ❌ sumとdiffは関数内だけのローカル変数のため、メインルーチン側には影響しません
```

### 💡 ポインタを使うメリット
ポインタを理解すると、**別のスコープ（ブロック）にある変数の値を直接操作できる**ようになります。
```text
[main]            [funcA]           [funcB]
+-------+         +-------+         +-------+

|  変数  |  <---  |ポインタ|  <---  |ポインタ|  （アドレスを通じて直接書き換え可能！）
+-------+         +-------+         +-------+
```

## 2. ポインタの基本概念

ポインタとは、**「メモリ上のアドレス（番地）」**のことです。

```c
int main(void) {
    int a;
    int *P; // ⇐ P: ポインタ変数の宣言

    a = 10;
    P = &a; // aのアドレスをPに代入（Pがaを指す状態にする）
}
```

* `int *` までが型名（イント・アスタリスク型 / intへのポインタ型）です。
* `&a` は「変数 `a` のアドレス」を取得する演算子です。

### 🧠 メモリのイメージ図
変数 `a` のアドレスが `1000番地` だった場合のイメージ：

| アドレス（番地） | 変数名 | 格納されている値 |
| :---: | :---: | :---: |
| **1000番地** | `a` | `10` |
| **2000番地** | `P` | **`1000`** （`a`のアドレス） |

### 🔍 画面への出力方法
ポインタが持つアドレスを出力するときは、書式指定子に `%p` を使用します。値は16進数で表示されます。
```c
printf("aの値: %d\n", a); // 10 が出力される
printf("Pの値: %p\n", P); // 0x7ffee3b... のようなアドレス（16進数）が出力される
```

## 3. 定義と使用時の表記ルール

`*` と `&` の役割は、宣言時（定義時）と使用時で異なるため整理が必要です。

### 間接参照
`*P = 100;` のように使うと、**「ポインタ `P` が指し示している先の変数（ここでは `a`）」**に直接アクセスし、値を書き換えることができます。

### 表記まとめ

| 変数の種類 | 定義時（宣言） | 使用時：値の操作 | 使用時：アドレスの操作 |
| :--- | :--- | :--- | :--- |
| **通常変数** | `int a;` | `a` （通常の値） | `&a` （自身の番地を取得） |
| **ポインタ変数** | `int *a;` | `*a` （指す先の値にアクセス） | `a` （格納しているアドレス） |

---

## 4. ポインタの型と一致のルール

ポインタを繋ぐ（アドレスを代入する）ときは、**必ずお互いの型が一致**していなければなりません。

```c
int *p1;    // int型へのポインタ（int型の変数のみ繋げられる）
double *p2; // double型へのポインタ（double型の変数のみ繋げられる）

int a = 10;
double b = 20.5;

p1 = &a; // ⭕ OK
p2 = &b; // ⭕ OK

// p1 = &b; ❌ 型が違うためエラー（int型ポインタにdouble型のアドレスは入れられない）
```

## 5. 関数でポインタを使う（実践）

ポインタを関数の引数に渡すことで、関数内からメインルーチンの変数を書き換えることができます。

### 🛠️ 実例：値を1増やす関数
```c
#include <stdio.h>

// 引数で「int型のポインタ」を受け取る
void plus1(int *a) { // 内部的には「int *a = &num;」と同じ状態になる
    *a += 1;         // ポインタaが指す先（mainのnum）の値を直接1増やす
}

int main(void) {
    int num = 10;
    
    // plus1関数はアドレスを要求しているため、&を付けて渡す
    plus1(&num);
    
    printf("numの値: %d\n", num); // 11 が出力される
    return 0;
}
```

### 🎯 最初の課題の解決（和と差を同時に反映する関数）
ポインタを使えば、最初にやりたかった「2つの整数を受け取って和と差を同時にメインルーチンに返す関数」が以下のように実現できます。

```c
#include <stdio.h>

// 計算結果を格納するためのポインタを引数にする
void sum_diff(int a, int b, int *p_sum, int *p_diff) {
    *p_sum = a + b;  // mainのans_sumに結果を書き込む
    *p_diff = a - b; // main의 ans_diffに結果を書き込む
}

int main(void) {
    int x = 15;
    int y = 5;
    int ans_sum = 0;
    int ans_diff = 0;

    // 格納先の変数に「&」をつけてアドレスを渡す
    sum_diff(x, y, &ans_sum, &ans_diff);

    printf("和: %d\n", ans_sum);  // 20
    printf("差: %d\n", ans_diff); // 10

    return 0;
}
```
