# C言語：関数への変数の受け渡し（値渡し）

C言語で通常の変数（配列ではない単一の変数）を関数に渡す際の仕組みと特徴を、見やすく整理しました。先の「配列の受け渡し（参照渡し）」との対比として、そのままノートや学習メモにコピー＆ペーストして活用してください。

---

## 📌 重要な基本鉄則

1. **変数は「コピー」される**
   * 関数に変数を渡すとき、渡されるのは変数の中身の「値」そのものです。
2. **値渡し（あたいわたし）**
   * このように値のコピーを渡す方式を「値渡し」と呼びます。
3. **元データは壊れない**
   * コピー先の関数内でいくら値を書き換えても、呼び出し元（`main`関数側）の元の変数には一切影響しません。

---

## 💻 コードの解説とポイント

### 1. 関数の呼び出し側（`main` 関数）
```c
int main(void) {
    int a = 10; 
    
    plus1(a); // 変数 a の「10」という値の「コピー」が関数に送られる
    
    printf("a = %d\n", a); // コピー元は変化しないため、結果は「10」のまま
    return 0;
}
```

### 2. 関数の定義側（受け取り側）
```c
void plus1(int a) { // mainの a とは「別メモリ」に作られたコピー
    a++; // ここで 11 に増えるが、変わるのはコピーされた a だけ
}
```
> 💡 **ポイント**
> `main`関数の `a` と `plus1`関数の `a` は、名前が同じでもメモリ上では**「完全に別の場所にある別物」**です。
> そのため、関数内でいくら数値を変更しても、`main`関数の `a` が変わることはありません。

---

## 📊 メモリと処理のイメージ

関数に渡されるのは場所（アドレス）ではなく、データの**「複製（コピー）」**です。

```text
[main関数側]                  [plus1関数側]
  変数 a                        変数 a (コピー)
+----------+                  +----------+

|    10    |  == コピー ==>   |    10    |
+----------+                  +----------+

     |                             |
 (影響なし)                     a++ を実行
     |                             v
+----------+                  +----------+

|    10    | (10のまま)       |    11    | (関数終了で消滅)
+----------+                  +----------+
```

---

## 🔄 「配列（参照渡し）」と「変数（値渡し）」の比較

| 渡す対象 | 渡し方の種類 | 関数に渡るもの | 関数内での変更 |
| :--- | :--- | :--- | :--- |
| **通常の変数** | **値渡し** | 値の**コピー** | 呼び出し元は**変わらない** |
| **配列** | **参照渡し** | 先頭の**場所（アドレス）** | 呼び出し元も**一緒に変わる** |
