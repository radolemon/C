# C言語：文字列操作関数 完全ガイド（`<string.h>`）

C言語で文字列（`char` 配列）を操作する場合、`<string.h>` ヘッダーファイルをインクルードする必要があります。
本稿では、基本となる4大関数（`strlen`, `strcpy`, `strcat`, `strcmp`）に加え、安全性を考慮した実践的なテクニックまで網羅して解説します。

---

## 📌 コピペでそのまま動く完全サンプルコード
以下のコードをコピーして `.c` ファイル（例: `main.c`）に貼り付ければ、ビルドして実際の動作を確認できます。

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    printf("=== 1. strlen 関数のテスト ===\n");
    char str_len[] = "test";
    // %zu は size_t 型を出力するための書式指定子
    printf("文字列: \"%s\" / 長さ: %zu\n\n", str_len, strlen(str_len));


    printf("=== 2. strcpy 関数のテスト ===\n");
    char src_cpy[] = "Hello";
    char dest_cpy[20]; // コピー先（サイズに余裕を持たせる）
    
    strcpy(dest_cpy, src_cpy);
    printf("コピー元: %s\n", src_cpy);
    printf("コピー先: %s\n\n", dest_cpy);


    printf("=== 3. strcat 関数のテスト ===\n");
    char dest_cat[20] = "test"; // "test" (4文字) + "\0" (1文字)
    char src_cat[] = "123";
    
    strcat(dest_cat, src_cat);
    printf("連結後の文字列: %s\n\n", dest_cat);


    printf("=== 4. strcmp 関数のテスト ===\n");
    char s1[] = "AB";
    char s2[] = "ABc";
    
    int result = strcmp(s1, s2);
    printf("s1: \"%s\", s2: \"%s\"\n", s1, s2);
    printf("strcmp の結果: %d\n", result);
    
    if (result == 0) {
        printf("結果: s1 と s2 は完全に一致しています。\n");
    } else if (result > 0) {
        printf("結果: s1 の方が辞書順で後ろです。\n");
    } else {
        printf("結果: s1 の方が辞書順で前です。\n");
    }

    return 0;
}
```

## 📘 1. strlen 関数（文字列の長さ）

文字列の**長さ（バイト数）**を取得する関数です。

### 📋 構文
```c
size_t strlen(const char *s);
```

### 🔍 仕組み
引数に渡された文字列の先頭から順番に文字を走査（カウント）し、**ヌル文字（`'\0'`）に到達した時点でカウントを終了**します。

### 💡 重要ポイント
* **ヌル文字（`\0`）は文字数に含まれません。**
  * 例: `"test"` の場合、メモリ上は `{'t', 'e', 's', 't', '\0'}` の5バイトですが、`strlen` が返す値は `4` です。
* **日本語（全角文字）の扱いに注意**
  * `strlen` が返すのは「文字数」ではなく「**バイト数**」です。UTF-8環境では日本語1文字が通常3バイトとしてカウントされるため、例えば `"あ"` の `strlen` は `3` になります。
* **戻り値の型は `size_t` 型**
  * 符号なし整数（環境により `unsigned int` や `unsigned long long`）であるため、`printf` で表示する際は **`%zu`** を使用します（`%d` を使うとコンパイル警告が出る場合があります）。

## 📙 2. strcpy 関数（文字列のコピー）

文字列を別の配列へ**上書きコピー**する関数です。

### 📋 構文
```c
char *strcpy(char *dest, const char *src);
```
* **第1引数（`dest`）**: コピー先（格納先）の配列
* **第2引数（`src`）**: コピー元（転送元）の文字列

### 🔍 仕組み
`strcpy(コピー先, コピー元)` のように、**「後ろから前へ」**データがコピーされます。コピー元の先頭から、終端のヌル文字（`'\0'`）までを丸ごとコピー先に書き込みます。

### 💡 重要ポイント
* **既存のデータは上書きされる**
  コピー先に元々文字列が入っていた場合、それらは完全に消去（上書き）されます。
* **⚠️ バッファオーバーラン（最重要の注意点）**
  C言語では、コピー先の配列サイズが十分に大きいかどうかを自動でチェックしてくれません。
  * `コピー先の配列サイズ < コピー元の文字数 + 1` の状態で実行すると、配列の範囲外のメモリを書き換えてしまい、プログラムの強制終了や、セキュリティ上の深刻な脆弱性の原因になります。

## 📗 3. strcat 関数（文字列の連結）

既存の文字列の後ろに、別の文字列を**付け足して連結**する関数です。

### 📋 構文
```c
char *strcat(char *dest, const char *src);
```
* **第1引数（`dest`）**: 連結先の配列（ベースとなる文字列が入っている）
* **第2引数（`src`）**: 追加したい文字列

### 🔍 仕組み
1. 連結先（`dest`）の文字列の終端にある **ヌル文字（`'\0'`）** を探し出します。
2. そのヌル文字が書き込まれている位置から、追加したい文字列（`src`）を上書きしていきます。
3. 最後に新しい終端としてヌル文字（`'\0'`）を自動で付与します。

### 💡 重要ポイント
* **⚠️ 配列サイズ（容量）の確保が必須**
  連結先（`dest`）の配列には、**「元々の文字数 ＋ 追加する文字数 ＋ 終端のヌル文字（1バイト）」** がすべて収まるだけの十分なサイズをはじめから宣言しておく必要があります。

```c
// ❌ ダメな例（初期化時の文字数分のサイズしかなく、追加すると溢れる）
char s1[] = "test"; 
strcat(s1, "123"); // メモリ破壊（バッファオーバーラン）

// ⭕ 正しい例（将来足される分を見越して大きなサイズを確保しておく）
char s1[20] = "test"; 
strcat(s1, "123"); // 4文字 + 3文字 + 1文字 = 8バイト。20サイズ以内なので安全
```

## 📘 4. strcmp 関数（文字列の比較）

2つの文字列を先頭から1文字ずつ比較し、**文字コードの差**を返す関数です。

### 📋 構文
```c
int strcmp(const char *s1, const char *s2);
```

### 🔍 仕組み（教科書 P.248 の補足）
2つの文字列を左（先頭）から1文字ずつ順番に比較していきます。
**最初に「異なる文字」が見つかった位置でストップ**し、その文字の「`s1の文字コード - s2の文字コード`」の計算結果（整数値）を返します。

### 📊 戻り値の見方
戻り値が具体的に「いくつ（数字）」であるかよりも、**「0か、正か、負か」**が重要になります。

| 比較結果の条件 | 戻り値 | 意味（辞書順での位置関係） |
| :--- | :--- | :--- |
| **`s1 == s2`** | **`0`** | 2つの文字列は**完全に一致**している |
| **`s1 > s2`** | **正の値（`> 0`）** | `s1` の方が、`s2` よりも**辞書順で後ろ**にある |
| **`s1 < s2`** | **負の値（`< 0`）** | `s1` の方が、`s2` よりも**辞書順で前**にある |

#### 📝 トレース例：`strcmp("AB", "ABc")` の場合
文字コードは、ASCIIコード（`'A'=65`, `'B'=66`, `'c'=99`, `'\0'=0`）として計算されます。

1. **1文字目の比較**: `s1` の `'A'` と `s2` の `'A'` ➡️ 一致（次へ）
2. **2文字目の比較**: `s1` の `'B'` と `s2` の `'B'` ➡️ 一致（次へ）
3. **3文字目の比較**: 
   * `s1` は文字が終わっているため **`'\0'`（文字コード: 0）**
   * `s2` は **`'c'`（文字コード: 99）**
   * ここで不一致が発生！
4. **内部の計算**: 
   \[\text{s1の文字} - \text{s2の文字} = 0 - 99 = -99\]
   結果は **`-99`（負の値）** となるため、`strcmp` は「`s1` の方が小さい（辞書順で前）」と判定します。

## 🛠️ 【ステップアップ】より安全な「n系関数」について
ここまで紹介した `strcpy` や `strcat` は、サイズ超過によるバグ（脆弱性）を引き起こしやすいため、現代のプログラミングでは、コピー・連結する文字数を制限できる **`strncpy`** や **`strncat`** を使うことが推奨されています。

```c
// コピーする文字数を最大 9 文字に制限する
strncpy(dest, src, 9);
dest[9] = '\0'; // strncpyは自動でヌル端しない場合があるため手動で入れるのが安全
```
