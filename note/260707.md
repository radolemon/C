# C言語：関数での配列の受け渡し（参照渡し）

C言語で関数に配列を渡す際の重要ルールと仕組みを、見やすく整理しました。そのままノートや学習メモにコピー＆ペーストして活用してください。

---

## 📌 重要な3つの基本鉄則

1. **配列名だけを書く**
   * 関数に配列を渡すときは、添え字（`[]`）をつけず「配列名だけ」を書きます。
2. **要素数をセットで送る**
   * 関数側は配列のサイズを自動で判断できないため、必ず「要素数」を一緒に渡します。
3. **配列名 ＝ 先頭要素の場所**
   * 配列名単体は、メモリ上の「配列の先頭要素の場所（アドレス）」を表します。

---

## 💻 コードの解説とポイント

### 1. 関数の呼び出し側（`main` 関数）
```c
int array[5] = {10, 20, 30, 40, 50};

plus1a(array, 5); 
//     ^^^^^  ^要素数も一緒に送る
//     配列名だけを書く（添え字はつけない）
```

### 2. 関数の定義側（受け取り側）
```c
void plus1a(int a[], int n) {
//              ^^^^ 要素数は書かない（空にする）
    for (int i = 0; i < n; i++)
        a[i]++;
}
```
> 💡 **ポイント**
> `array[]` と `a[]` は名前が違っても、メモリ上の**「同じデータ」**を指しています。
> これを **参照渡し（アドレス渡し）** と呼び、関数内での変更は呼び出し元の配列に直接反映されます。

### 3. プロトタイプ宣言
```c
void plus1a(int [], int);
//              ^^ 配列部分は「配列名」も「要素数」も書かない
```

---

## 📊 メモリと処理のイメージ

関数に渡されるのはデータそのものではなく、配列が割り当てられている**「メモリの場所（アドレス）」**です。

| 配列名 | [0] | [1] | [2] | [3] | [4] |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **`array`**（main関数側） | 10 | 20 | 30 | 40 | 50 |
| **`a`**（plus1a関数側） | 👆 | 👆 | 👆 | 👆 | 👆 |

※ `a` は `array` と全く同じ場所を見ているため、`a[i]++` をすると元の `array` の中身が直接 `11, 21, 31...` と書き換わります。
