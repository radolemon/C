# C言語の重要概念：const修飾子と変数の有効範囲（スコープ）

C言語における「関数の引数に対する読み込み制限（`const`）」と、「変数がどこから参照できるか（スコープ）」について解説します。

---

## 1. 配列の書き込み制限（const修飾子）

関数に配列を渡す際、**関数内で配列の要素を変更しない（読み込み専用にする）場合は、必ず引数の型に `const` 修飾子を付与**します。これにより、意図しないデータの破壊を防ぎ、コンパイル時にエラーとして検知できるようになります。

### 1-1. コピー元を保護する配列コピー関数
コピー元（`a`）は変更しないため `const` を付け、コピー先（`b`）は書き換えるため `const` は付けません。

```c
#include <stdio.h>

/* a_copy: 配列 a の内容を配列 b にコピーする */
void a_copy(const int a[], int b[], int n) {
    for (int i = 0; i < n; i++) {
        b[i] = a[i]; /* OK: コピー先への書き込み、コピー元からの読み込み */
        
        /* 
        a[i] = b[i]; 
        ↑ もしこのように誤って const である a に書き込もうとすると、
          コンパイルエラー（assignment of read-only location）が発生します。
        */
    }
}
```

### 1-2. constを付けるケースと付けないケース

#### 💡 付けるケース：要素の平均値を求める関数（読み込みのみ）
配列 `v` の値を計算に使うだけで、配列そのものは一切書き換えないため `const` を付けます。

```c
/* a_ave: 配列の要素の平均値を求める */
double a_ave(const int v[], int n) {
    int sum = 0;

    for (int i = 0; i < n; i++) {
        sum += v[i]; /* 配列の値は参照されるだけで、変わりません */
    }

    return (double)sum / n;
}
```

#### 🛠️ 付けないケース：要素を反転する関数（書き込みあり）
配列 `v` の中身を直接入れ替える（書き換える）必要があるため、`const` は付けてはいけません。

```c
/* rev_intary: 配列の要素を反転（前後を入れ替え）する */
void rev_intary(int v[], int n) {
    for (int i = 0; i < n / 2; i++) {
        int tmp = v[i];           /* 一時退避用の変数 */
        v[i] = v[n - 1 - i];     /* 前方に後方の値を代入 */
        v[n - 1 - i] = tmp;       /* 後方に退避していた値を代入 */
    }
}
```

## 2. 変数の有効範囲（スコープ）

C言語の変数には、定義する場所によって「どこから使えるか（有効範囲）」が決まっています。

* **グローバル変数（大域変数）**：すべての関数からアクセス可能。プログラム開始時に1度だけ初期化。
* **ローカル変数（局所変数）**：定義されたブロック `{ }` 内でのみ有効。関数呼び出しやブロック侵入のたびに初期化。

> ⚠️ **重要ルール：識別子の隠蔽（シャドウイング）**
> 同じ名前の変数が複数ある場合、**より内側（有効範囲が狭い）の変数が優先**され、外側の変数は一時的に見えなくなります。

### 2-1. スコープ実験コード

以下のコードは、グローバル変数、`main`関数直下のローカル変数、`for`文内のローカル変数の挙動を示したものです。

```c
#include <stdio.h>

/* =========================================================================
   1. グローバル変数 (大域変数)
   ========================================================================= */
int x = 10; /* プログラム実行時に1度だけ初期化される */

void print_x(void) {
    /* ここには同名のローカル変数がないため、グローバル変数の x が参照される */
    printf("print_x内:   x = %d  (グローバル変数)\n", x); /* 値：10 */
}

/* =========================================================================
   2. メイン関数とローカル変数 (局所変数)
   ========================================================================= */
int main(void) {
    /* main関数ブロック直下で有効なローカル変数 x */
    int x = 20; 

    print_x(); /* print_x関数を呼び出し（出力：10） */

    /* 有効範囲がより狭い「ローカル変数」が優先されるため、20が出力される */
    printf("main直下:    x = %d  (mainのローカル変数)\n", x); /* 値：20 */

    /* ---------------------------------------------------------------------
       3. ブロック内（for文）スコープ
       --------------------------------------------------------------------- */
    for (int i = 1; i <= 2; i++) {
        /* for文のブロック内でのみ有効なローカル変数 x */
        /* ループが回る（ブロックに入る）たびに毎回初期化される */
        int x = i * 100; 

        printf("forループ内: x = %d (for内のローカル変数)\n", x); /* 値：100, 200 */
    }

    /* for文を抜けると、for内の x は消滅するため、main直下の x (20) が再び見える */
    printf("forループ外: x = %d  (mainのローカル変数)\n", x); /* 値：20 */

    return 0;
}
```

### 2-2. 実行結果

上記プログラムを実行すると、出力は以下のようになります。

```text
print_x内:   x = %d  (グローバル変数) -> 10
main直下:    x = %d  (mainのローカル変数) -> 20
forループ内: x = %d (for内のローカル変数) -> 100
forループ内: x = %d (for内のローカル変数) -> 200
forループ外: x = %d  (mainのローカル変数) -> 20
```
