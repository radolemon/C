# C言語：文字の扱い（char型とASCIIコード）

C言語における `char` 型は、1バイト（0〜255）の範囲を持つ**整数用の型**です。画面に表示される「文字」の正体は、この整数データ（ASCIIコード）です。

## 1. 文字と文字列の基本ルール

* **文字**： `'A'` のように、シングルクォーテーション（ `' '` ）で囲む。代入できるのは1文字のみ。
* **文字列**： `"Hello"` のように、ダブルクォーテーション（ `" "` ）で囲む。

### サンプルコード

```c
#include <stdio.h>

int main(void) {
    char c = 'A'; // 1文字のみ代入可能
    int n = 65;   // 'A' のASCIIコード

    // char型の変数cを異なる書式で出力
    printf("%c\n", c); // 出力: A （文字として表示）
    printf("%d\n", c); // 出力: 65（10進数の整数として表示）

    // int型の変数nを文字として出力
    printf("%c\n", n); // 出力: A （整数65に対応する文字を表示）

    return 0;
}
```

## 2. ASCIIコード表（主要部分の抜粋）

`'0'〜'9'`、`'A'〜'Z'`、`'a'〜'z'` の各範囲内では、**値が1ずつ連続して増加すること**がシステム（規格）で保証されています。

| 文字 | 16進数 | 10進数 | 備考 |
| :---: | :---: | :---: | :--- |
| **'0'** | `30` | `48` | 連番で `57` ('9') まで続く |
| **'A'** | `41` | `65` | 連番で `90` ('Z') まで続く |
| **'a'** | `61` | `97` | 連番で `122` ('z') まで続く |

---

## 3. 文字の操作を行うプログラム例

ASCIIコードが「ただの連続した整数」であることを利用すると、ループ処理や文字変換が簡単に実装できます。

### ① 'A' 〜 'Z' を連続で出力する
連続した数値であることを利用し、`for` 文のカウンタ変数に直接文字を指定できます。

```c
#include <stdio.h>

int main(void) {
    // 'A'から'Z'まで1ずつ増やしながら出力
    for (int c = 'A'; c <= 'Z'; c++) {
        printf("%c ", c);
    }
    printf("\n");
    return 0;
}
```

### ② 大文字 ⇔ 小文字の相互変換
ASCIIコード上、同じアルファベットの大文字と小文字の間隔は**常に「32」**です。

```c
#include <stdio.h>

int main(void) {
    char c = 'A';

    // 大文字 → 小文字（32を足す）
    c += 32; 
    printf("小文字: %c\n", c); // 出力: a

    // 小文字 → 大文字（32を引く）
    c -= 32; 
    printf("大文字: %c\n", c); // 出力: A

    return 0;
}
```

> 💡 **より実戦的なTips**
> 実際の開発では、マジックナンバー（固定の数値）である `32` を直接足し引きする代わりに、`c += ('a' - 'A');` と書くと、意図が明確になり可読性が上がります。
